# JSQLite2 alpha.7 static demo

Use an HTTP server; open index.html and run the two supplied examples.
The engine is entirely browser-side TypeScript compiled to JavaScript.
Experimental read-only support is not full SQLite compatibility.
Chinook is an immutable MIT-licensed fixture; see CHINOOK-LICENSE.md.
SQLite development reference is deliberately pinned to 3.53.4, not latest upstream.
