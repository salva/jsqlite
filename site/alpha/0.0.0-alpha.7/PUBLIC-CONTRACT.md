# Experimental alpha.7

Browser-only read-only SQLite translation; no native SQLite, WASM or query server.
UTF-8, UTF-16le and UTF-16be are supported within the currently admitted subset.
Unsupported compositions are rejected, not a full SQLite compatibility promise.
Chromium finite local package/demo/Fetch checks passed; no all-browser, universal
termination, statistical performance or beta-completion claim.
The development reference remains SQLite 3.53.4, not latest upstream.
