SMALL API. REAL SQLITE FILES.

From URL to rows.

1. Serve a clean snapshot

Publish an immutable SQLite main database file. Apply pending WAL/journal changes before publishing. For another origin, configure CORS to allow browser access.

2. Open, prepare, step

Execution is asynchronous; local column access isn't. INTEGER values use bigint, blobs use Uint8Array, and SQL NULL is null.

3. Release your handles

Finalize each statement and close its connection. Use cancellation and resource limits for untrusted SQL or files.

import { open } from './assets/engine/index.js';

const db = await open(new URL(
  './assets/chinook.sqlite', import.meta.url
));
try {
  const { statement } = db.prepare(
    'SELECT Name FROM Artist LIMIT 5'
  );
  if (statement) {
    try {
      while (await statement.step() === 'row') {
        console.log(statement.column(0));
      }
    } finally { statement.finalize(); }
  }
} finally { db.close(); }

Serve the complete ESM module tree, not only index.js. No npm registry release is available yet. Build from the tagged source for a local package; see the build instructions and API reference.

EXPERIMENTAL, WITH HONEST BOUNDARIES

A working core. Not all of SQLite.

What it does

Read-only queries on immutable database files, with implemented SELECT, joins, aggregates, subqueries, CTEs, windows, functions and index paths at documented admission boundaries. UTF-8 and both UTF-16 encodings are supported.

What it doesn't promise

Not every query composition or optimizer path is implemented. Unsupported cases should fail explicitly; report incorrect results. Chromium has tested coverage; other browsers are not yet certified. Large temporary working sets are memory-limited; OPFS spill is not advertised.

What stays out of scope

Writes, transactions, WAL recovery, native/WASM query backends and external extensions. Publishers supply clean immutable files; the browser does the query work.

Read the evidence-backed alpha matrix before choosing JSQLite for an application. The broad compatibility goal is ongoing, not a percentage already achieved.
