Missing table, omitted argument, unknown name and explicit temp lookup give no rows; absent schema errors (`unknown database absent`). Parameter argument syntax fails near `?`. Tail ` SELECT 1` remains unconsumed. Index list/info/xinfo, FK list and database list succeed natively but fail publicly. Native database_list includes temp after the explicit-temp probe; filename values are oracle-work paths, not a proposed public filename contract.

Generated Lemon tables contain PRAGMA reductions from `parse.y:1714–1721`; `parse.ts:productionAction` supplies no cmd PRAGMA semantic. Its `action()` converts an accepted reduction lacking semantic data into a syntax error at the first token. Consequently public `prepare` cannot reach schema, lowering, or VM. Separately `src/index.ts` currently treats every represented non-SELECT as permanently excluded mutation: a caller contract that must distinguish bounded read PRAGMA from actual mutation if later implementation lands. Do not fix this node.
