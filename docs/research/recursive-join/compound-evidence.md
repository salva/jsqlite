LIMIT0 bypasses production but not resolution/arity diagnostics. Producer parameters and private/work bounds remain shared with the enclosing VM.

This retains the already accepted materialization adaptation: full producer work and storage are charged before the requested arm's first output, unlike a streaming native coroutine. It is not a TypeScript/browser necessity, native work/allocation parity or a planner guarantee. No queue algorithm substitution was introduced. Mixed operators, extra recursive declarations, derived/group/window arms, RIGHT/FULL and physical recursive-term joins remain outside this route. Existing native shared merge is reused for the admitted operators; there is no replacement set evaluator.
