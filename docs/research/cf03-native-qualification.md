## Bounded qualification decision

This development-only Linux x86_64 qualifier retains historical exact SHA acceptance and admits fresh ELF only when **all allocated section contents, virtual addresses, sizes, types, flags and alignment** match an independently source-verified build. Only nonallocated/debug sections and allocated GNU build-id are excluded. Unknown compiler/platform/code differences fail closed, even if SourceID matches. This is deliberately narrower than arbitrary same-source rebuild support. It neither proves authenticity of a malicious loader nor accepts arbitrary binaries on semantic SourceID alone; normal trusted local build inputs remain the boundary.
