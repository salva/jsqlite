## Implementable first-slice contract

1. **Separate page owner.** Use a statement-private page-number arena with byte-authoritative page buffers, derived MemPage metadata and explicit leases/generations. Share existing KeyInfo/record/Mem comparison and execution-wide budget/control. Preserve immutable main, sibling sorter/window/compound and rowid RowSet work. A page-number map is addressing, not ordered-key evaluation.
2. **Real cells and free space.** Preserve index headers, sorted two-byte pointer slots, arbitrary physical cell placement, ordered freeblocks/fragments and content boundary. Translate native allocation/defrag/free/coalescing branches, not unconditional compaction. Interior index dividers own packed records and left children; right child belongs to the header. Preserve local-payload distribution, overflow next-pointer pages, and separate transient balance insertion cells.
3. **Typed cursor seam.** Proposed async IndexMoveto returns `{res, empty, epoch}` or throws; cursor owns state, page/ix, retained parent stack and child-slot indices, CellInfo and key/overflow/last caches, saved key and skip/fault state. Result is packed-current versus unpacked-target comparison, not array rank. Empty returns successful res=-1 with INVALID cursor. Found uses defaultRc0, checks errors before publishing caller state, and requires nonempty res0. eqSeen records equal compared prefixes and is not synonymous with final res0; a fresh probe initializes it at its caller.
4. **Source-shaped search.** Preserve rightmost-page shortcuts, unknown-positive shortcut fallback, root reset/error order, within-page binary search, local fast versus overflow reconstruction branches, interior equality positioning and miss child descent. On failed child acquisition release any invalid child and restore parent. Do not add GE/LE repositioning to IndexMoveto or reuse a prior sign without cursor/key/epoch/producer validity.
5. **Identity and ownership.** Full KeyInfo includes encoding, field counts, collations, DESC and NULL flags. Preserve packed INTEGER/REAL serial identity, BigInt integers, real values, NULL and BLOB bytes even where numeric equality equates INTEGER1/REAL1. Ordinary unpacked comparison is not the STAT4 error channel. Explicitly scope/copy input Mem values and release scratch/keys/leases across success and error.

## Inferences and decisions still required

Parent must settle these seams before VM consumers. In particular root2 was proposed, not established by a complete OpenEphemeral/CreateTable trace here.

Use physical page/scratch/cache/saved-key/undo capacity reservations against the existing aggregate budget; aliases must not double-charge pages and freelist capacity remains retained. Replacement peak cannot be hidden by net accounting. This proposed basis differs from current logical-entry thresholds: reconcile API/resource semantics before delivery, without changing sibling policy silently.

Private in-memory ownership permits page buffers/objects/BigInt/async adaptations, not global sorted-array substitution. File locks, file IO/journals/WAL and direct-file overflow optimization are inapplicable to a nonpersistent arena. Auto-vacuum pointer-map branches are inactive only under explicit private autoVacuum=false. Acquisition/ref/init/release, freelist ownership, write barriers and failure cleanup remain relevant. Bounded comparison/copy/defrag checkpoints need semantic-preserving control plumbing; synchronous comparator reuse alone does not prove responsiveness.

Mutation publication requires exclusive operation ownership across suspension, affected-cursor save before edits, charged scratch and registered undo/write ownership, a final checkpoint, and complete noncancellable unwind preserving the primary error. The exact rollback/FAULT choice remains unresolved; no per-operation native atomicity claim is made.
