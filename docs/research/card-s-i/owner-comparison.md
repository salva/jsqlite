## Further mutation and continuation trace

`balance_nonroot` collects up to neighboring sibling pages and parent divider cells, preserving divider bytes before parent edits. It incorporates overflow cells at their ordered offsets, verifies sibling page types, computes byte occupancy and divider positions, then adjusts rightward packing: an empty right sibling is illegal, so redistribution is not optional. It reuses old pages before allocation, orders page numbers, installs new parent divider cells, edits pages in an order avoiding borrowed-cell destruction, frees unused pages and releases sibling/scratch ownership on the shared cleanup path. Index leaf divider cells are real keys (unlike intkey leaf-data separators); an array split cannot silently omit them. `balance` retains scratch until subsequent parent redistribution finishes, then frees it on all exits.

`saveCursorPosition` rejects pinned cursors, normalizes SKIPNEXT, copies key before releasing pages and publishing REQUIRESEEK, and invalidates caches even if copy fails. Restore preserves FAULT error, clears saved key only after successful seek, and publishes SKIPNEXT when restored position differs. ClearTable first saves all affected cursors, invalidates overflow caches, then recursively clears the root; errors propagate without pretending reset succeeded. `fillInCell` writes size/header, local payload then overflow chain; allocation failure is not a successful insertion. These are explicit private-owner test requirements, not existing TS guarantees.

WhereEnd closes levels inside-out: resolves continuation, emits the level's next/return operation, drains IN loops with early-out/open-state guards, resolves break and skip-scan/LIKE continuations, and only then emits nullable-side null-row/reopened-index/Gosub handling. RIGHT JOIN postprocessing and coroutine rewrite are separate branches before common-index column rewriting. The target admission deliberately excludes those nullable/RIGHT/FULL branches rather than claiming their translated coverage. Shared Return/Gosub ownership must survive ordinary/INNER/scalar callers, not be independently generated by the dedup storage primitive.

## Overflow and terminal ownership closure

`clearCellOverflow` bounds the local cell before reading its overflow pointer, derives the exact chain length from remaining payload, rejects invalid page numbers/reference counts before freeing, unreferences each retrieved page even when free fails, and propagates the first error. `fillInCell` allocates each overflow page before linking it through pPrior, initializes its next pointer to zero, releases prior page only after link publication, and releases pending ownership on allocation/pointer-map error. `clearDatabasePage` recursively clears child cells and rightmost child before zeroing the retained root; every error goes through page release. `BtreeCloseCursor` unlinks cursor first, releases page stack and overflow/saved-key allocations, and closes a BTREE_SINGLE private tree only when last cursor is gone. TS budget accounting and async unwind must preserve this ownership ordering, not just decrement a count at statement end.

WhereEnd's final index rewrite retains table references when not covered unless IDX_ONLY promises coverage, in which case it raises internal planner error. Rowid/IfNullRow substitutions and expression-index fallback are distinct; expression-index residual branches cannot be blindly marked consumed. It restores query-loop estimate, unwinds indexed-expression ownership and deletes WhereInfo after generating loop and column rewrites. This is the required residual/caller boundary for the ordinary/INNER/scalar builders; admission cannot erase untested dependencies merely because PK identity is available.

The two current TS Case5 lowerers still acquire rowid with Rowid and use RowSetTest. Primary extraction is not wired into either path; this corroborates the unchanged six red assertions and rules out planner-gate-only repair. Simple persistent scalar uses the common builder target, not a new evaluator. Future runtime implementation must couple these producers and callers with a translated private index; no aggregate expansion is implied.
