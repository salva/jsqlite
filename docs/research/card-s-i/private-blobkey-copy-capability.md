# Private BLOBKEY bounded copy capability

Current owner: `src/internal/private-blobkey-pages.ts`. This is a representation optimization, not a different B-tree algorithm or a public raw-byte API.

## Source comparison and boundary

Pinned SQLite 3.53.4 `btree.c:IndexMoveto` (6036, overflow branch6163) allocates padded record scratch, publishes cell index, reads payload, clears overflow validity and compares packed/unpacked keys. `accessPayload`5125–5345 validates payload ranges, traverses/acquires overflow pages, copies bounded chunks and unrefs even on errors. Native `copyPayload` copies bytes without per-property dispatch. TS retains those loops, cache, scratch, range checks, checkpoints and primary-preserving release order. The former `TypedArray.set(borrowedProxy.subarray(...))` incurred per-byte Proxy liveness checks.

A module-private WeakMap now associates each borrowed byte view with a synchronous copy closure. It validates that exact view's existing liveness and uses the captured TypedArray set intrinsic into owned scratch. The function never returns raw bytes, never invokes a user callback and never awaits between validation and copying. Callers still checkpoint before copying and hold the same lease/exclusive arena operation across suspension. All three overflow readers (seek, scoped payload and saved-position snapshot) use the same primitive. No local-page, allocator, balance, key comparison or publication algorithm changes.

Each acquired lease remains128 deterministic bytes; each derived subview remains64 until revocation. The copy closure/WeakMap association is included in that descriptor allowance, not separately retained page data. Scratch payload+18 for seek, existing snapshot/payload charges, doubled overflow cache, physical pages, refs and all existing limits are unchanged. No whole-heap/malloc parity claim. A revoked Proxy may still be referenced externally; its inaccessible closure retains the same backing view already retained by that Proxy, and checks revocation before copying. Public inspection remains readonly/revocable and buffer exports remain forbidden.
