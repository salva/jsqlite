## 1. Prerequisite repairs: preserve the construction owner

Do these before any full Insert consumes its helpers. Do not replace native allocator/parser/free-space algorithms.

1. **Byte authority:** `borrowedBytes` currently admits indexed assignment and mutating `set/fill/copyWithin`; raw/result/index views are revocable but writable. `allocatePage` and `PrivateIndexPage` construction also need explicit trust boundaries. Give external inspection read-only revocable views; private owning routines receive raw storage only under an unforgeable arena operation token. Construction installation remains an owned-copy fixture seam, disallowed during operations/live cursor references. Direct exported standalone page construction is a fixture owner, not authority to mutate an arena page. Never accept external writes that bypass nCell/nFree, entry counters, epoch or cache invalidation. Do not merely freeze the outer result object.
2. **One operation gate:** cursor's `#busy`, page's `#mutating`, arena's `#busy` and no-leases construction restriction are not a full operation capability. Add arena-wide exclusive async read/seek/write/lifecycle admission with an internal token allowing nested helper calls without reacquiring the gate. External acquisition/construction/mutation/close and hook reentry must reject during suspension. Internal cursor leases/ancestor references are legal; arbitrary external leases are not. Keep construction wrappers' no-leases precondition; add internal token-taking allocator/free/fill/clear/page-edit variants used by Insert. Do not release the writer path merely to pass construction admission. Save peer cursor leases first, then enforce native ref/cycle guards. Admission failures before mutation are retryable; token cleanup is noncancellable.
3. **Cursor registry/state:** register cursors by arena/root and lifetime, not just reserve128 bytes. Add saved packed key, length, skipNext/error, REQUIRESEEK/SKIPNEXT/FAULT, cell-info validity, overflow-valid and at-last flags (or equivalent explicit fields). Centralize page release and cache reset. Root/child/page changes clear info size/ValidNKey/ValidOvfl; root also clears AtLast. Cache capacity is distinct from validity. Fix cleanup to attempt every release even when a hook throws (`#root` currently sequentially releases without this guarantee). Preserve primary error.
4. **Entry transfer:** current `insertCell` always reserves a new entry, `dropCell` decrements, and staging teardown decrements. Add explicit internal NEW / REPLACE / TRANSFER admission modes and linear transfer ownership; public foundation insertion remains NEW. A transferred cell is removed from its source count exactly once and added to destination without testing maxEntries again. Transit/pending entries remain in arena aggregate authority; clearing staging scratch alone must not delete a moved entry. Do not balance by repeated public insert/drop admissions or by temporarily relaxing the limit.
5. **Structural publication:** add native zeroPage/copyNodeContent and internal staged-cell transfer/reset separate from scratch destruction; derived leaf/childPtrSize/cellOffset/nCell/nFree must be reinitialized after root type changes. Add bounded CellArray source descriptors (page identity + offset/end or owned scratch), lazy cached sizes and edit/rebuild helpers. Internal descriptors are not arbitrary retained borrowed proxies. Add arena rekey identity support for native sibling page-number swaps, updating map keys, page identity and page counters together with no exposed transient pending-byte identity; do not reorder keys or substitute a logical sorted tree.

These are local changes to authority, admission and metadata relationships around the accepted byte owner; not grounds for a wholesale rewrite or bypass evaluator.

## 2. Typed Insert caller contract

Proposed internal `insertIndex(cursor, payload, options, control)`; return completion, not a fabricated insertion position. Payload always owns a packed record and exact packed byte length (native pKey/nKey); BLOBKEY has no separate pData/nData/nZero. Optional unpacked Mem fields are a search optimization only, copied before await with matching KeyInfo, valid nField and defaultRc=0/eqSeen=0. Preserve INTEGER/REAL, NULL, text encoding/collation, BLOB and error distinctions through existing typed comparator/unpacker. Packed bytes remain publication authority even when search uses unpacked fields. Producer asserts equivalence to packed key under the same KeyInfo; no SQL-text equivalence or generic prefix token. Full record field validation belongs to the unpack/search owner (`btreeMoveto`: nField>0 and <=nAllField), not a hand-written alternate record evaluator.

Snapshot mutable input before suspension, charge packed and optional Mem ownership at peak, probe work/cancel/deadline in nonyielding <=4096-byte chunks. Small legacy copy may use the existing bounded path; larger missing-probe input rejects before mutation, not after starting overflow publication. The optional seek representation does not replace packed maxKeyBytes admission. Preformat is a separate ownership protocol, not an arbitrary byte flag.

Options: append hint, savePosition, optional **trusted current seek evidence**, optional bulk-load hint only if caller explicitly supplies native equivalent. Append does not invent a different BLOBKEY comparator/balance; native unpacked IndexMoveto ignores the intkey bias. Default bulk=false.

Native seekResult=0 is overloaded: absent/unknown causes a seek; nonzero -1/+1 promises a successful equivalent-key immediately adjacent position. Equality0 is not an ordinary reuse shortcut. savePosition=true instead asserts already positioned on equal key, loc=0. Reject invalid savePosition evidence before mutation. Do not expose arbitrary scalar `seekResult` as sufficient authority. A private token should bind cursor identity/root/KeyInfo, owned target identity or semantic producer proof, latest seek generation, arena epoch, signed result, state and position. No tokens on failed seeks. Every seek (even equal target), clear/save/restore/close, page-local mutation, balance/rekey, or fault invalidates prior tokens. Equivalent alternate unpacked/packed targets need producer proof; otherwise reseek. A stale token is rejected or treated as absent before mutation according to one documented internal caller policy (recommend absent/reseek); never trusted by matching epoch alone. This is a safety adaptation for async ownership, not a new search algorithm.

Caller comparison sign is **current cell versus desired key**. loc<0 inserts after current cell (increment ix if nonempty), loc>0 inserts before; empty leaf INVALID with loc=-1 inserts at0. Equality can occur on interior index cells and means replacement there, not descent to a leaf. eqSeen is comparison diagnostic, not replacement or unique-conflict authority. `vdbe.c:IdxInsert` marks its column cache stale after the Btree call including error; no VM change is authorized here, but the future caller contract must require that invalidation. Found/NotFound supply defaultRc0 seek evidence; a prefix seek is not automatically proof for complete packed publication.

## 3. Insert control order, equal replacement and overflow

Translate `BtreeInsert` branches in this order:

1. Save other same-root cursors when Multiple applies, excluding writer, before search and byte mutation. First save error aborts; earlier peer saves may remain REQUIRESEEK. Nonvalid peers release pages. Do not clear writer and lose source shortcuts. Validate nonzero-loc path still exists. If writer REQUIRESEEK, moveToRoot clears saved key and resets flags (this is **not restore**); FAULT returns stored error, empty-root sentinel is tolerated.
2. For loc0 and !savePosition, seek optional unpacked fields (defaultRc0/eqSeen0), otherwise unpack packed via btreeMoveto. No fresh entry admission until equality/new status is known; at capacity equality replacement is legal.
3. **Equal packed payload length:** getCellInfo and call btreeOverwriteCell first. This optimization compares length, not byte identity. Bounds-check local payload, then overwrite changed local bytes only; for overflow, write local first, acquire each overflow page, require raw/uninitialized and sole ref, read next only if another page is needed, compare/memmove changed payload, release each before advancing. Retain existing overflow chain and cell slot. Child prefix on interior remains untouched. No fill/new overflow allocation or drop/insert in this branch. No entry-count change. Logical content mutation still invalidates seek/caller column evidence; overflow address cache may retain capacity but must be invalidated conservatively before re-use unless proved same cell/chain. Failure after any write terminally faults the private arena.
4. Other branch: compute page free space; fillInCell owns temporary cell and allocates its overflow chain **before** destroying old cell. Use existing local distribution/varint/padding and prior-link publication → unref previous → retain new → zero-next order. New-cell scratch disposal never frees the chain. On error, no journal rollback is promised: fault/dispose arena, release all pending/raw leases and scratch once, do not claim the abandoned chain was rolled back.
5. Set cell info size0. For equality validate idx; acquire write authority, preserve old four-byte left child into new interior cell; clear old overflow; invalidate overflow cache; if old cell size equals new cell size and old payload wholly local (autoVacuum=false), bounds-check and memcpy whole cell directly. Otherwise drop old slot after clear, then insert replacement at same idx. Preserve native primary-clear error through drop short-circuit. Entry identity transfers old→replacement, never NEW even if temporarily absent. For new loc<0/nonempty increment ix and clear key/overflow flags. Otherwise use existing ix.
6. insertCellFast (child0) publishes resident cell or ordered staged cell. Only new key admission increases logical aggregate once; staged versus resident is not another entry. On staging call balance, clear key/overflow validity first. After balance **including failure**, reset current overflow staging and set cursor INVALID so save cannot parse an unstable position. Under private partial-error policy, **on failure after partial mutation only**, also trip arena/cursors to FAULT, release all staging payload scratch across affected pages, abandon logical entries to terminal disposal, and do not present a valid tree or reuse a token. Clearing staging metadata is not individually clearing its overflow chains.
7. On successful balance and savePosition, release all path pages, own inserted packed key/length, then REQUIRESEEK. Native post-balance key-copy allocation can fail; reserve/copy according to translated ordering and fault if this occurs after structural mutation. Without balance native may leave a positioned cursor, but API does not promise arbitrary insertion position. Scratch and input finally release; preserve first operational error over release-hook errors.

## 4. Balance: CellArray, divider ownership and propagation

Implement dispatcher and all reachable BLOBKEY nonroot branches, not a split-at-half approximation.

**Dispatcher (`9130ff`):** loop current→parent. Stop when no staged cells and nFree*3<=usableSize*2. Root overflow checks anotherValidCursor, then balance_deeper; successful expansion publishes depth1, ix0, root parent slot0, child current, and loops on child. Root without overflow stops. Nonroot current must have sole native-equivalent ref (ancestor/self cycles are corruption); make parent writable, compute parent free. BLOBKEY never meets intKeyLeaf quick-balance predicate. Allocate new page-size divider scratch, call nonroot(parent,parentSlot,scratch,isRootParent,bulk). Keep prior divider scratch live through this call, then free prior; new scratch persists until subsequent nonroot call or dispatcher exit. Clear child's staged count even on failure, release child, decrement depth and assign parent current before loop/error exit. Always release final scratch.

**Nonroot (`8245ff`) order:**

- Parent has0/1 staged cell, if present at iParentIdx. Initialize CellArray, done flags and sentinel; choose up to3 siblings using native nxDiv formulas (bulk may choose2 on extreme right). Resolve right boundary child pointer in parent, acquire siblings **right-to-left**, compute each free space. Remove intervening parent dividers as encountered. Preserve divider contents after drop: freeSpace overwrites first four bytes, not remaining key bytes, so use charged source descriptors/copies of key content before source reuse; do not clear divider overflow! Those chains move with actual index entries. Parent staged divider transfers too.
- Allocate scratch from bounded nMaxCells (sum old nCell plus per-page overflow capacity, aligned to4), cell descriptors/sizes and one-page divider-copy area. Validate sibling page flags equal. Concatenate physical cells and adjacent ordered staged cells in native order. For BLOBKEY leafData=false: **include old parent divider records in the sequence**. Leaf correction4 strips child pointer and pads short leaf divider cells to minimum4. Interior divider's left child becomes old left sibling's right-child. Preserve source end bounds and lazy size cache.
- usableSpace=4096−12+leafCorrection. Start from native cntOld/szNew (used bytes+staged bytes+slots), move excess cells right and fill left space with cached cell sizes. Non-leafData consumes one sequence entry as each parent divider, not duplicated leaf boundary key. Preserve all invalid/nonprogress bounds. Then mandatory right-to-left redistribution: r=cntNew[i−1]−1, d=r+1 (leafData0); move until nonempty right meets native byte-size comparison, with bulk early-stop only after right nonempty. Update counts and reject empty/nonprogress left ranges. This prevents an empty right sibling; not an optional performance step.
- Reuse old pages first, transfer refs/ownership into new array and check expected reference count (1 plus current cursor's existing ref for affected page); allocate extras with native nearby/bulk hint, zero same page flags. Up to5 destinations. Native sorts **page numbers by rekeying page identities**, not the cell sequence. Proposed arena adaptation is bounded nonyielding map/identity swaps equivalent to the three PagerRekey calls: no I/O/pending-byte physical page required, existing references still denote the same bytes, entries/derived pgno move consistently. Test shuffled freelist allocations and retained references. This is representation-level identity bookkeeping, not a sorted-array substitute or claim of Pager flags parity.
- Update parent right boundary to last new pgno. If interior and sibling count changes, copy original rightmost right-child to new rightmost. Insert parent dividers before editing siblings: interior boundary cell's child becomes new left sibling right-child; leaf adds four-byte child prefix; size4 leaf records are reparsed for real interior size (do not blindly add4). Parent insert replaces child with new left pgno, stages adjacent dividers if necessary. Transfer entry/overflow-chain ownership into parent. Bounds against original source end remain checked.
- Edit siblings in native downward-then-upward dependency order, skipping done pages: cells moving left require left destination updated before source, moving right require right destination first. Translate editPage: free leading/trailing ranges, slot shift, insert head, include staged cells, append tail; on inability to edit, populate sizes and use **native rebuildPage fallback**, copying self-page source to page scratch before overwrite. Do not always rebuild as an unexplained substitution. Publish nCell/nOverflow/header, then caller sets nFree=usableSpace−szNew. Release staged scratch only once consumed; counts TRANSFER without global admission.
- If root parent emptied and header fits child's free space, require sole child; defrag child, copyNodeContent to root, free child (balance-shallower branch belongs here even for insertion-related propagation). Otherwise finish. Free unreused old pages. Cleanup always frees CellArray scratch and releases every acquired old/new page exactly once, including partially acquired arrays, preserving first rc.

**Deeper (`9049ff`):** write root; allocate child near root; copyNodeContent (content area and header/slots; reinit derived page, compute free, may fail). On error release child, return no child. On success transfer staged indices/cell buffers and entry ownership root→child; zero root with child flags minus LEAF, install right-child. Do not teardown staged scratch while transferring it. Stable root pgno2, no extra logical entry. Dispatcher owns returned child reference. This ordering is mandatory, not root recreation via installPage.

## 5. Save/restore, clear and last close

Implement after authority/admission and before relying on mutation with multiple cursors; fixtures may test these primitives ahead of Insert.

- **saveCursorPosition:** only VALID/SKIPNEXT, no existing saved key; pinned rejects first. SKIPNEXT→VALID preserving skipNext; ordinary VALID resets skipNext0. saveCursorKey reads full packed payload (including overflow), owns length+17 zero padding and charged descriptor; key is published only after successful read. Success releases all cursor pages and becomes REQUIRESEEK. On save read failure release pending key but retain source position/path as C does; clear ValidNKey/ValidOvfl/AtLast on both success and failure. Release-hook failure under TS adaptation requires complete path unwind and honest error, not half saved/half leased. Failed pre-write save aborts Insert/Clear without mutating pages; completed peers remain saved. Cache allocation capacity may remain but validity is false.
- **restore:** fast no-op below REQUIRESEEK. FAULT returns stored error without search. REQUIRESEEK sets INVALID before btreeMoveto(saved packed key,length,bias0). On success free saved key; nonzero result replaces skipNext; zero preserves prior skipNext; if skipNext!=0 and resulting state VALID set SKIPNEXT. Empty tree remains INVALID. On seek error native retains saved key while state has already become INVALID; do not silently reset REQUIRESEEK or free the saved key as if success. Preserve key for later explicit ClearCursor/close; any retry semantics must be explicit, not accidental double restore. No structural mutation occurred here, so a plain read error need not fault the arena; mutable partial failures do. ClearCursor frees saved key and sets INVALID; page release is separate as upstream.
- **SKIPNEXT consumers:** restoring to nearby greater cell sets positive; Next changes SKIPNEXT→VALID and returns current cell once when positive; negative behaves symmetrically for Previous. Opposite direction advances normally. Original skipNext from a deletion-style save is preserved on exact restore. No Next/Prev implementation credit yet; preserve state and reject absent consumers honestly rather than flattening to boolean `found`.
- **ClearTable:** saveAllCursors(root,except none) first; stop on first save error. Incrblob invalidation is unreachable for BLOBKEY. clearDatabasePage keeps root, not arena recreation. Check pgno/count; acquire/init; native BTREE_SINGLE skips general external-ref guard, but private admission still excludes unsafe borrowed writes and cycle traversal needs bounded depth/visited ownership proof. For each slot in order recurse left child first (if interior), then clear that cell overflow; after loop recurse right child; then add nCell to optional pnChange for BLOBKEY (including interior dividers), then free child pages or write/zero root preserving BLOBKEY flags|LEAF. Do not drop slots as traversal progresses, do not count only leaves, and do not free parent before children/overflow. Release page on every exit. Use explicit bounded frame stack if desired, preserving depth-first order and charging capacity; no unbounded recursive JS stack. Successful clear leaves saved peers REQUIRESEEK, root empty and aggregate logical count0; restores yield INVALID. Physical pages go to existing freelist and remain charged. Partial clear faults whole arena, cleans scratch/path/cache, preserves primary error; no retry against partially cleared tree.
- **CloseCursor:** under gate, unlink from registry first; release all pages; native unlockBtreeIfUnused releases page1 only when inTransaction==TRANS_NONE (no OS lock counterpart in this arena); free overflow capacity and saved key; if BTREE_SINGLE and registry empty close arena, otherwise leave arena alive; detach cursor. The downstream `sqlite3BtreeClose` rolls back the native transaction, closes Pager, disposes schema/temp/BtShared and handle; private terminal disposal replaces nonpersistent rollback/Pager teardown, **not** its transactional guarantees. OpenEphemeral uses BTREE_OMIT_JOURNAL|BTREE_SINGLE: therefore last cursor must dispose arena buffers/results/staged scratch even in FAULT. Existing `cursor.close` merely releases cursor charges and existing `arena.close` rejects outstanding refs; they are not this owner yet. Distinguish owning ephemeral cursor from fixture/nonowning construction cursors so earlier foundation tests are not silently relabeled. Rejected busy/foreign-lease close must not unlink irreversibly. Once admitted, cleanup is idempotent, attempts all cursor and arena disposals even if observers fail; primary execution failure wins over close/release errors, otherwise first cleanup error reports. No await cancellation in teardown. Arena+registry+cursor allowance ownership must unwind failed cursor publication and last-close once, including unpositioned cursor charges and auxiliary results.

## 6. Resource and fault policy

One execution budget owns physical buffers, all retained/pending/peak scratch, saved keys, optional Mem snapshot, path capacity, CellArray descriptors/sizes/source ends/done/cnt arrays, two concurrently live divider buffers, self-page rebuild scratch, page leases, staged descriptors/results and cursor registry tokens. Fixed deterministic metadata constants need documented finite capacities and tests, not native sizeof/malloc claims. Reuse existing128/64 allowances where they actually cover fields; add explicit allowances for new dynamic owners before allocation/publication. Entry counters remain sole authority: NEW increments once, REPLACE/TRANSFER conserve even at maxEntries; failed unpublished NEW refunds, terminal partially published errors invalidate rather than infer rollback. Key limit rejection precedes structural publication; byte peak failures during balance can occur after insertion and must FAULT. Account conservative copies honestly (do not claim native lazy-pointer memory equality).

Check work/cancel/deadline before each page acquisition/allocation and per bounded cell/freeblock/freelist/CellArray loop; payload copying <=4096 chunks; checkpoints before page-sized nonyielding header/slot/rekey publication. Existing synchronous snapshot probe is required for large caller-owned data before the first await. No hooks or suspension may expose half-published identity/count/slot transitions to another owner. Release/FAULT disposal must not require budget admission or cancellable checkpoints. First structural error remains authoritative even when staged scratch reset or release hooks also fail. Do not FAULT for a safely rejected oversized key/entry, stale token/reseek policy, pinned save or outer busy admission before mutation. No native NOMEM parity is implied by deterministic budget failure points.
