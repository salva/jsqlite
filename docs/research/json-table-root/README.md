# JSON table document admission and root conversion

`json.c:jsonEachFilter` resets the cursor, admits JSONB or parses document SQL text, then obtains `sqlite3_value_text(argv[1])`, treats NULL as empty, takes the root C-string length and validates/looks up the path. `JsonTableRewind` now passes the ordinary root Mem to `openJsonTableCursor`; that owner performs conversion only after document admission, through the existing private-copy `jsonSqlText` helper. It never changes the caller register. BLOB conversion uses the Mem's actual encoding; no universal UTF8 reinterpretation. The lookup and hidden root use the converted, NUL-terminated path, as upstream xColumn does. Document NULL never touches root; malformed document wins over invalid root.

No new evaluator, eager column conversion or algorithm substitution. Existing demand, traversal, metadata and owning document snapshots remain unchanged. Reservations now include the converted path after document parsing and refund through existing close/error cleanup. Logical budgets are not physical heap equivalence.
