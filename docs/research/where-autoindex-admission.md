### Immutable planner and descriptor

Extend the shared loop union with an explicit automatic capability; do not fabricate a persistent schema IndexNode/root page or insert it into schema indexes. Descriptor identity is plan-owned, carrying source identity, ordered driving term admissions (including original operand, affinity/effective collation/provenance), nEq, covering field-to-source-column map, rowid tail, KeyInfo, optional safe build predicate and optional Bloom specification. Existing PhysicalIndex identity for persistent indexes stays authoritative. A discriminated runtime descriptor is an ordinary TS representation adaptation to native transient Index, not an alternate planner.

Translate candidate insertion/pruning/path solver ownership: prerequisites include source/barrier and driving RHS masks; WO_EQ/WO_IS non-rowid columns only when affinity-compatible and outer-join compatible. NOT INDEXED, INDEXED BY, recursive/correlated source, RIGHT/WHERE_RIGHT_JOIN, OR-subclause gates remain native gates. Keep BigInt masks and LogEst logical values; source rSetup=estLog(N)+N plus table28 (ephemeral/view−25), multiplier and nonnegative clamp; rRun=LogEstAdd(logN,43), nOut43, with source comparisons against existing alternatives. Setup is charged once per path, run per outer row. Translate the native small-outer/automatic preference checks, not an ad hoc fixed row threshold or always-auto picker. No prepare-time scan to guess cardinality; schema stats/defaults remain shared.

During construction expand **all** ready eligible driving columns with native deduplication/order, not just the candidate seed. Cover every column needed by projection, residuals and downstream expressions plus rowid. KeyInfo uses comparison collation for driving fields, BINARY for extras/tail and database encoding. Duplicate logical keys remain distinct by rowid tail. EQ skips NULL probe; IS preserves native NULL equality semantics and its source-specific Bloom eligibility. ### Bloom is central, not an optional afterthought

Auto construction's10000-byte filter and separate persistent-index `sqlite3ConstructBloomFilter` are different producers of the same shared VM primitive. Auto integration may land first because it establishes transient record/probe dispatch; **standalone Bloom does not depend on automatic-index implementation** and must have a parallel candidate/build handoff. Native standalone size derives from table estimates and clamps10000..10000000; translate native worth-it/stats/outer/IN/pulldown conditions rather than enabling every join. Text-only auto keys need source's numeric-capable eligibility (all string keys collide).

Translate filterHash as uint64 modular addition using BigInt.asUintN: integer/IntReal values, REAL via sqlite3VdbeIntValue, Str/Blob4093 plus native flag contribution, NULL contributes zero. Add and probe use identical coerced register values/type flags. This requires Mem owners to expose/derive native hash-relevant distinctions, not JS string hashing. Modulo by nBytes*8, bit index/byte update identical. FilterAdd sets bit; Filter jumps to no-match only for absent bit, else authoritative seek and residual comparison. In ordinary membership terminology collisions are false positives, never false negatives for any admitted equal key. Native comments' terminology must not invert branch behavior. Unit tests must compare raw hashes/bits and collision controls to source, including signed wrap, REAL truncation and integer/REAL equal keys, NULL/IS, NOCASE and BLOB/string flag contribution. Filter pulldown consumes ready prerequisites and clears level regFilter as native; no duplicate filter skipped across unsafe LEFT/LTORJ/IN barriers.

### Execution and resource contract

No build during prepare and no step-time replanning. Once state, Bloom blob and private tree are execution/frame-owned. Reset clears Once/positions/build/filter/covering bindings and refunds private allocations while preserving SQL bindings; next execution rebuilds, including changed parameter-dependent safe build predicates. Bind expiry/reprepare stays shared ReprepareContext: retained schema/plan remains immutable, replacement releases old execution before publication; failure retains original error and bindings under existing contract. Correlated invocation needs native frame/invocation Once lifetime proof before admission, never statement-global cached data.

Charge Bloom bytes, page arena, packed-record scratch and transient Mem at existing privateState limits before allocation/publication; private build/probe traversal uses shared work/scheduler/abort/deadline checks. Partial build failure must not become a scan fallback or success. Halt/error/cancel/deadline/reset/finalize/close release only owned tree/blob/register resources once, invalidate cursor/record/Once state, preserve original error and refund accounting. Reuse follows existing OpenEphemeral encoding validation **before** clearing old owner; detach-before-close/reacquire and failure cleanup remain authoritative. No new budget, cross-statement cache, hidden spill service or API option. Capacity rejection is valid explicit operation failure; do not destroy another statement's resources.
